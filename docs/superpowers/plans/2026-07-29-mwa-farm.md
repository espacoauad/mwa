# MWA FARM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the MWA FARM — an animated, Township-style farm scene where 8 habit "pillars" grow from seed to full bloom over the person's 90-day journey, plus decorative animals/milestones that appear on fixed days, all derived from the existing `diaAtual` value with zero new database state.

**Architecture:** Pure-function growth engine (`src/utils/farm/crescimento.js`) computes pillar unlock day, growth stage, and unlocked decorations from a single `diaAtual` input. Two data files (`pilares.js`, `decoracoes.js`) hold content. Two SVG components (`PlantaFazenda.jsx`, `AnimalFazendaSvg.jsx`) render the visuals from those computed values. `MwaFarm.jsx` is the modal screen that ties it together, opened from a card in the Ferramentas tab — same lazy-modal pattern as the other games built earlier this project.

**Tech Stack:** React (JSX), Tailwind v4 (utility classes + `@theme` custom colors), `node:test` for logic tests, plain CSS `@keyframes` for animation (no canvas, no animation library).

## Global Constraints

- Zero changes to the database — all farm state is derived from `diaAtual` (already provided by `AppContext`), never persisted separately.
- No interaction with the sementes/recompensas economy — MWA FARM does not grant or consume 🌱.
- Visuals are SVG only; animation is CSS `@keyframes` only (no canvas, no animation library) — mirrors the constraint stated in the spec to keep the app light.
- Every animated CSS class must be neutralized under `prefers-reduced-motion: reduce`, following the exact pattern already in `src/index.css:123-131`.
- All user-facing text is bilingual (PT/EN), following the `ingles` boolean convention from `useIdioma()` used throughout the codebase.
- The modal is accessible: `role="dialog"`, `aria-modal="true"`, Esc closes it, focus moves to the dialog on open — same pattern as `src/components/game/MolduraJogo.jsx`.
- Every interactive element (plant, animal) is a real `<button>` with a descriptive `aria-label`, never a `div` with `onClick`.
- Lives inside the Ferramentas tab as a destaque card (not a new bottom tab bar entry — reversed decision from brainstorming).
- If `diaAtual` is missing/undefined (e.g. a demo context with no login), the farm must default to day 1 rather than crash.

## Scope note (transparency, not in the original spec)

The spec calls for SVG illustration for the 8 plants and 5 animals, but does not mandate a rendering technique for the 6 background decorations (fence, beehive, barn, scarecrow, bunting, "90 days" sign). To keep this plan shippable in one pass, **Task 9 renders those 6 decorations as curated emoji**, not bespoke SVG — they're ambient/non-interactive, so the quality bar is lower than the hero elements (plants and animals), which do get full custom SVG. Flag this to the proprietária when demoing; swapping emoji for SVG later is a small, isolated follow-up if she wants it.

```js
// Motor de crescimento da MWA FARM — funções puras, sem UI, sem banco.
// Tudo é derivado de diaAtual (já existe no AppContext); nada aqui persiste
// estado próprio.

import { PILARES } from '../../data/farm/pilares.js'

const INTERVALO_LIBERACAO_DIAS = 4

function indiceDoPilar(pilarId) {
  return PILARES.findIndex((p) => p.id === pilarId)
}

// Segue o mesmo padrão de diaLiberacaoJogo em src/utils/jogosLiberacao.js:
// id desconhecido cai no dia 1 em vez de quebrar.
export function diaLiberacaoPilar(pilarId) {
  const indice = indiceDoPilar(pilarId)
  return indice === -1 ? 1 : 1 + indice * INTERVALO_LIBERACAO_DIAS
}

export function pilarLiberado(pilarId, diaAtual) {
  return diaAtual >= diaLiberacaoPilar(pilarId)
}
```

```js
const DIAS_POR_ESTAGIO = 20
const ESTAGIO_MAXIMO = 3 // 0=semente, 1=broto, 2=floração, 3=plena

export function estagioDoPilar(pilarId, diaAtual) {
  const diaLiberacao = diaLiberacaoPilar(pilarId)
  if (diaAtual < diaLiberacao) return -1
  return Math.min(ESTAGIO_MAXIMO, Math.floor((diaAtual - diaLiberacao) / DIAS_POR_ESTAGIO))
}
```

```jsx
// Molde de planta compartilhado entre os 4 estágios da MWA FARM.
// Cada pilar usa a mesma "planta-base" (caule + folhas), variando só a cor
// de destaque e a "coroa" (flor/fruto/espiga) no topo — assim 8 pilares × 4
// estágios não exigem 32 ilustrações desenhadas do zero.

const TERRA = '#8A6A48'
const CAULE = '#5C8A3F'
const FOLHA = '#7CA85C'

function Coroa({ coroaId, cor, escala }) {
  const deslocamentoY = 34 - 18 * escala
  const transformBase = `translate(32 ${deslocamentoY}) scale(${escala})`

  switch (coroaId) {
    case 'tomate':
      return (
        <g transform={transformBase}>
          <circle cx="-5" cy="0" r="6" fill={cor} />
          <circle cx="5" cy="2" r="6" fill={cor} />
          <circle cx="0" cy="-6" r="6" fill={cor} />
        </g>
      )
    case 'flor-azul':
      return (
        <g transform={transformBase}>
          {[0, 72, 144, 216, 288].map((angulo) => (
            <ellipse key={angulo} cx="0" cy="-7" rx="4" ry="7" fill={cor} transform={`rotate(${angulo})`} />
          ))}
          <circle r="3.5" fill="#F6E9D2" />
        </g>
      )
    case 'girassol':
      return (
        <g transform={transformBase}>
          {[0, 45, 90, 135, 180, 225, 270, 315].map((angulo) => (
            <ellipse key={angulo} cx="0" cy="-8" rx="3" ry="6" fill={cor} transform={`rotate(${angulo})`} />
          ))}
          <circle r="5" fill="#7A5A32" />
        </g>
      )
    case 'lavanda':
      return (
        <g transform={transformBase}>
          {[-6, -2, 2, 6].map((x) => (
            <ellipse key={x} cx={x} cy={-6 - Math.abs(x)} rx="2.2" ry="7" fill={cor} />
          ))}
        </g>
      )
    case 'trigo':
      return (
        <g transform={transformBase}>
          <rect x="-2" y="-14" width="4" height="14" rx="2" fill={cor} />
          {[-10, -6, -2, 2, 6, 10].map((y) => (
            <ellipse key={y} cx={y > 0 ? 4 : -4} cy={y} rx="3" ry="2" fill={cor} />
          ))}
        </g>
      )
    case 'milho':
      return (
        <g transform={transformBase}>
          <ellipse cx="0" cy="-6" rx="6" ry="11" fill={cor} />
          <path d="M-6 -6h12M-6 -2h12M-6 -10h12" stroke="#FFF8E6" strokeWidth="1.2" opacity="0.5" />
        </g>
      )
    case 'erva':
      return (
        <g transform={transformBase}>
          <path d="M0 0C-8 -8 -8 -18 0 -20C8 -18 8 -8 0 0Z" fill={cor} />
          <path d="M0 -2V-18" stroke="#3C5233" strokeWidth="1" opacity="0.4" />
        </g>
      )
    case 'laranjeira':
      return (
        <g transform={transformBase}>
          <circle cx="-6" cy="-2" r="5.5" fill={cor} />
          <circle cx="6" cy="-2" r="5.5" fill={cor} />
          <circle cx="0" cy="-10" r="5.5" fill={cor} />
        </g>
      )
    default:
      return <circle transform={transformBase} r="5" fill={cor} />
  }
}

export default function PlantaFazenda({ estagio, cor, coroaId, tamanho = 64, rotulo }) {
  const estagioSeguro = Math.min(3, Math.max(0, estagio ?? 0))
  const alturaCaule = 6 + estagioSeguro * 6
  const escalasCoroa = [0, 0.55, 0.8, 1]
  const escalaCoroa = escalasCoroa[estagioSeguro]

  return (
    <svg
      viewBox="0 0 64 64"
      width={tamanho}
      height={tamanho}
      role={rotulo ? 'img' : 'presentation'}
      aria-label={rotulo}
      aria-hidden={rotulo ? undefined : true}
    >
      <ellipse cx="32" cy="58" rx="16" ry="5" fill={TERRA} />
      <rect x="30" y={58 - alturaCaule} width="4" height={alturaCaule} rx="2" fill={CAULE} />
      {estagioSeguro >= 1 && (
        <>
          <ellipse
            cx="24"
            cy={58 - alturaCaule + 4}
            rx="7"
            ry="4"
            fill={FOLHA}
            transform={`rotate(-25 24 ${58 - alturaCaule + 4})`}
          />
          <ellipse
            cx="40"
            cy={58 - alturaCaule + 4}
            rx="7"
            ry="4"
            fill={FOLHA}
            transform={`rotate(25 40 ${58 - alturaCaule + 4})`}
          />
        </>
      )}
      {escalaCoroa > 0 && <Coroa coroaId={coroaId} cor={cor} escala={escalaCoroa} />}
    </svg>
  )
}
```

Create `demo/farm.jsx`:

```jsx
// Demo da MWA FARM — mostra a fazenda em vários dias da jornada lado a lado,
// para verificar visualmente a progressão de crescimento. Só para desenvolvimento.
import React, { useState } from 'react'
import ReactDOM from 'react-dom/client'
import './demo.css'
import { IdiomaProvider } from '../src/context/IdiomaContext.jsx'
import { DemoFarmProvider } from './stubs/AppContext.jsx'
import MwaFarm from '../src/components/game/MwaFarm.jsx'

const DIAS_DE_EXEMPLO = [1, 11, 15, 30, 60, 89]

function Demo() {
  const [dia, setDia] = useState(1)
  return (
    <div className="mx-auto max-w-md space-y-3 p-5">
      <p className="text-sm font-semibold text-verde">Escolha o dia da jornada:</p>
      <div className="flex flex-wrap gap-2">
        {DIAS_DE_EXEMPLO.map((d) => (
          <button
            key={d}
            type="button"
            onClick={() => setDia(d)}
            className={`rounded-full px-3 py-1.5 text-xs font-bold ${
              dia === d ? 'bg-verde text-creme' : 'bg-white text-verde'
            }`}
          >
            Dia {d}
          </button>
        ))}
      </div>
      <DemoFarmProvider diaAtual={dia}>
        <MwaFarm onFechar={() => {}} />
      </DemoFarmProvider>
    </div>
  )
}

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <IdiomaProvider>
      <Demo />
    </IdiomaProvider>
  </React.StrictMode>,
)
```
