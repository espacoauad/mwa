# MWA Rodada 2 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Conversão e medição na landing (quiz de leads, Pixel/GA4, suporte visível, code-splitting), doc de teste de tagline, e limpeza de marcas (Herbalife/Whey 3W) no conteúdo do app.

**Architecture:** Landing (`landingpage/`, React 18 + Vite 6 + Tailwind v4) ganha módulo de analytics carregado em idle, seção de quiz com captura via Netlify Forms e code-splitting com `React.lazy`. App (raiz) tem substituições de conteúdo em `src/data/*` e componentes de UI, sem mudança de lógica.

**Spec:** `docs/superpowers/specs/2026-07-17-mwa-landing-rodada2-design.md` (fonte de verdade, incl. §6 limpeza de marcas).

## Global Constraints

- Sem promessa de emagrecimento garantido; sem urgência apelativa; CRN presente onde já está; "Nutricionista" NUNCA adjacente a "20+ anos"; ZERO menção a Herbalife/Whey 3W/nomes de marca de suplemento em qualquer superfície ao final; zero "21 dias" em copy nova.
- Motion só transform/opacity, `prefers-reduced-motion` respeitado; zero bibliotecas novas de runtime (analytics via snippets inline, sem SDK npm).
- Analytics NÃO pode degradar LCP: carregar em `requestIdleCallback` (fallback `setTimeout 2000`), e só se o ID existir.
- WhatsApp de suporte: `https://wa.me/5562994246775` com mensagem própria da landing (nunca "21 dias").
- Verificação por task: `npm run build` do projeto tocado + greps indicados. Commits: um por task, mensagens dadas.
- Landing tasks (1–5): trabalhar em `landingpage/`. App tasks (6–7): raiz. Branch `security/correcoes-criticas`; commitar SÓ os arquivos da task.
