# 🚀 Criar Repositório no GitHub (2 minutos)

## Passo 1: Acessar GitHub

1. Abra: **https://github.com/new**
2. Você vai ver um formulário

## Passo 2: Preencher Dados

Preencha assim:

```
Repository name:     MWA
Description:         MWA — Método Wanessa Auad (opcional)
Public:              ✓ (deixe marcado)
Add .gitignore:      Nenhum (já temos)
Add LICENSE:         Nenhum (opcional)
```

## Passo 3: Criar

Clique no botão verde **"Create repository"**

## Passo 4: Pronto!

GitHub vai mostrar uma tela com instruções.

Você vai ver algo tipo:
```
…or push an existing repository from the command line

git remote add origin https://github.com/espacoauad/MWA.git
git branch -M main
git push -u origin main
```

Perfeito! É exatamente o que vamos fazer!
