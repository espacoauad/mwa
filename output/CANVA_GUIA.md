# Template Canva Editável — Guia Passo-a-Passo

## O que é

Um template no Canva que replica a comanda Espaço Auad, permitindo que você edite preços, sabores e itens **sem precisar gerar um novo PDF** cada vez que faz alteração.

## Como Criar o Template

### Passo 1: Acessar Canva

1. Abra https://www.canva.com no seu navegador
2. Faça login (ou crie conta gratuita se não tiver)

### Passo 2: Criar Design Customizado

1. Clique em **"Create a design"** (botão azul)
2. Clique em **"Custom size"**
3. Defina as dimensões:
   - **Largura:** 15
   - **Altura:** 20
   - **Unidade:** Centimeters
4. Clique **"Create"**

Você agora tem uma página em branco com 15cm × 20cm.

### Passo 3: Construir o Layout

#### 3.1 Cabeçalho

1. **Add text → "Heading"**
2. Digite: `ESPAÇO AUAD — COMANDA`
3. **Formatação:**
   - Fonte: Helvetica (ou sans-serif)
   - Tamanho: 48pt (grande o suficiente para 11pt impresso)
   - Estilo: Bold
   - Cor: Preto
   - Alinhamento: Center
4. Posição: Topo da página (altura ~1cm)

#### 3.2 Linha Divisória

1. **Add shape → "Line"** (linha horizontal)
2. Largura: 14cm (quase a largura toda)
3. Cor: Preto
4. Espessura: 2-3px
5. Posição: Logo abaixo do cabeçalho

#### 3.3 Seção Combos de Shake (Caixa)

1. **Add shape → "Rectangle"** (retângulo)
2. Propriedades:
   - Fill: Branco (ou transparente)
   - Stroke: Preto (borda 2px)
3. Tamanho: ~13.5cm × 2.5cm
4. Posição: Logo abaixo da linha divisória

5. **Inside the box, add text:**
   - **Título:** "COMBOS DE SHAKE" (Bold 11pt, topo)
   - Linha divisória interna (horizontal cinza clara)
   - **Combos (um por linha, 8pt regular):**
     ```
     ( ) Shake Base ........................... 29
     ( ) Shake + 2 Chás ....................... 39
     ( ) Shake Base + Whey .................... 39
     ( ) Shake Base+Whey+2 Chás .............. 49
     ( ) Shake + Hype Drink ................... 59
     ( ) Shake + Hype Drink GS ............... 65
     ```
   - Use tabs ou espaços para alinhar preços à direita

#### 3.4 Adicionais de Bebidas

1. **Add text → "Body"**
2. **Título:** "ADICIONAIS DE BEBIDAS" (Bold 11pt)
3. **Conteúdo (8pt, 3 linhas compactas):**

   ```
   ( ) Fiber Líquida 8,00  |  ( ) Lift Off 20,00

   ```

#### 3.5 Campo de Observações

1. **Add text:**

   - Usar underline (_) ou linha sob o texto

## Passo 4: Salvar e Compartilhar

1. Clique em **"Share"** (canto superior direito)
2. Selecione **"Anyone with link can edit"**
3. Copie o link e salve em local seguro
4. Compartilhe o link com a equipe se necessário

**Exemplo de link:**
```
https://www.canva.com/design/DAAbcDefGhIjK/edit
```

---

## Passo 5: Editar Futuramente

Sempre que quiser fazer alterações:

1. Abra o link do seu design Canva
2. Clique **"Edit a copy"** (ou edite direto se salvou em conta)
3. **Duplo-clique** no texto que quer editar
4. Altere preços, nomes, sabores conforme necessário
5. Salve automaticamente (Canva salva em tempo real)
6. **Exporte como PDF** quando pronto:
   - Clique em **"Download"** (canto superior direito)
   - Selecione **"PDF"**
   - Clique **"Download"**

## O Que é Editável

✅ **Preços** — Duplo-clique em qualquer valor e altere (ex: 29 → 35)  
✅ **Nomes de itens** — Adicione/remova sabores, combos, adicionais  
✅ **Títulos de seções** — Personalize se necessário  
✅ **Cores de fundo** — Opcional, atualmente branco  
✅ **Fonte/tamanho** — Mantenha Helvetica para consistência, mas pode ajustar  

❌ **Não mexer:**
- Tamanho da página (15×20cm — fixo)
- Resolução (Canva cuida disso automaticamente)
- Moldura dos Combos (replicar se duplicar a comanda)

## Troubleshooting

**P: O texto não está alinhado corretamente**  
R: Use a ferramenta "Align" do Canva (na barra superior). Selecione múltiplos elementos e clique "Align Left" ou "Align Right".

**P: Como fazer checkboxes?**  
R: Use o símbolo Unicode `☐` (caixa vazia) ou desenhe pequenos quadrados com a ferramenta "Shape → Rectangle".

**P: Posso alterar as cores?**  
R: Sim, mas mantenha Preto & Branco para impressão (evite cinzas, pode sair borrado).

**P: Como adiciono um novo sabor?**  
R: Duplo-clique no texto de sabores, insira o novo sabor, e separe com `|` (pipe).
